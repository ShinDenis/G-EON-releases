# G-EON — релизы

Живые субтитры с переводом стрима: русский, английский, казахский. Работает на компьютере, без облака.

Установщики для Windows — в разделе [Releases](../../releases).

## Установка
1. Скачайте `G-EON-<версия>-setup.exe` из последнего релиза и запустите. Права администратора не нужны.
2. Если Windows покажет «Windows защитила ваш компьютер» — «Подробнее» → «Выполнить в любом случае»
   (установщик пока не подписан).
3. При первом запуске приложение скачает модели (несколько гигабайт), дальше работает без интернета.

Это тестовая версия. После проверки нажмите «Бенчмарк устройства» и пришлите отчёты из папки,
которая открывается кнопкой «Открыть папку отчётов».
